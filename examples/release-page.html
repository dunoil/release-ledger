Read these first — 2 breaking changes

RL-1011 API v1 responses lose the `total_tax` alias. The deprecated alias for `tax_total` is removed in API v1 responses. The field itself is unchanged; update integrations that read the alias before upgrading.

RL-1009 Legacy XLS export retired. The pre-2019 .xls exporter is removed. CSV and XLSX exports cover every report it produced; saved schedules were migrated automatically.

The nine changes

Added

Banking

RL-1042

Self-reconciling bank feeds

Feeds now match transactions to invoices automatically and show their working. Anything unmatched lands in one review queue instead of three reports.

Added

Reports

RL-1037

Accountant-ready audit pack

One export with the trial balance, every journal entry and the full change history of each figure, signed with the release id of the data it came from.

Added

Billing

RL-1031

Proration previews

See exactly what a plan change will charge, day by day, before you confirm it. No more surprise invoices explained after the fact.

Changed

Invoices

RL-1028

Invoice numbers are now per-entity

Multi-entity accounts get independent sequences per entity. Existing numbers are untouched; the change applies from this release forward.

Changed

Search

RL-1025

Search covers attachments and notes

Receipts, PDFs and free-text notes are indexed alongside transactions, with the match highlighted in place.

Fixed

Imports

RL-1019

CSV imports no longer drop the last row

Files without a trailing newline silently lost their final transaction. Found because a customer counted. Fixed, with a regression test named after them.

Fixed

Tax

RL-1016

Rounding on multi-rate invoices

Invoices mixing two tax rates could be a cent out against the ledger total. The ledger total now wins, always.

Breaking

API

RL-1011

API v1 responses lose the `total_tax` alias

The deprecated alias for `tax_total` is removed in API v1 responses. The field itself is unchanged; update integrations that read the alias before upgrading.

Breaking

Exports

RL-1009

Legacy XLS export retired

The pre-2019 .xls exporter is removed. CSV and XLSX exports cover every report it produced; saved schedules were migrated automatically.
