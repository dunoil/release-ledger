Read these first — 2 breaking changes

RL-1011 API v1 responses lose the `total_tax` alias. The deprecated alias for `tax_total` is removed in API v1 responses. The field itself is unchanged; update integrations that read the alias before upgrading.

RL-1009 Legacy XLS export retired. The pre-2019 .xls exporter is removed. CSV and XLSX exports cover every report it produced; saved schedules were migrated automatically.
